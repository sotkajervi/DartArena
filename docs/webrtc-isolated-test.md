# Isolated browser media benchmark
This is a local P2P WebRTC test on a GitHub runner, not a DartArena end-to-end or Cloudflare SFU capacity test. No authentication, production services, external ICE servers, deployment or secrets. One browser with synthetic 640×360/15 fps video and generated audio, two peers per pair. Tests one, five, ten and 25 pairs in order, stopping on a failed stage; measures ICE/DTLS setup time, received bytes, decoded video frames, packet counters and RTT. All peer connections and tracks are closed. Limits: 25 pairs, 15-second measurement, hard workflow/job timeouts. Each peer must receive audio and video, remain connected and decode at least 12 fps; aggregate packet loss must be at most 1%. Same-host conditions cannot represent real-world network performance. Real SFU testing requires a separate authorized SFU app and test database.
