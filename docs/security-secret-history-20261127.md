# Phase 8.3: bounded Git history secret diagnostic

Existing media-secret-scan.cjs checks selected tracked text files in the working tree only. This isolated diagnostic scans unique reachable Git blobs from fetched branches and tags, including old deleted versions, using high-confidence patterns and service-role JWT claim detection. Public Supabase keys and anon JWTs are not classified as secret. Outputs only object IDs, categories and coverage counts, never credential contents or file paths. Binary and >10 MiB blobs are excluded; unreachable/deleted refs, remote logs, artifacts, external secret stores and unknown formats are outside scope. Candidates can be false positives, including documentation/test material. No credential validation against live services, no history rewrite, no rotation and no deployment. Green only means diagnostic execution completed. Review findings privately before any remediation.
