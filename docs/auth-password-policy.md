# Auth password policy
Registration and password recovery require at least 8 characters, without mandatory character classes. Login imposes no new length requirement, preserving older users. Server Auth minimum length must separately be configured to 8 in the Supabase dashboard; browser checks are not a security boundary. No Auth settings, sessions, video code, or production changes in this branch.
