# SEER local 501 preview — isolated first step
The diagnostic SeerVisit receives normalized observations and resolves hits. This new pure preview maps those observations to existing local-h2h-engine.submit arguments, checks the actual last double, rejects a fourth dart or additional darts after a terminal hit, and blocks missing/conflicting observations. Normal visits require three resolved darts; early bust/checkout may be previewed from fewer. The existing engine still determines state transitions, history, undo, and statistics. Existing engine counts three darts for bust; this preserves current behavior. No connection to live campaign rooms, no hardware validation, no auto-submission, no new event assumptions. Before integration confirm real device event order, removal/reconnection, explicit confirmation, stale turn binding, single-consumption/idempotency, and manual fallback. Simulated inputs only; no server, media or production changes.
