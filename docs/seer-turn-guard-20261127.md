# SEER turn guard (simulation only)
One explicitly armed board visit bound to an immutable engine state object. A verified source epoch and clear-board acknowledgement are prerequisites; stale epochs and repeated throw IDs are rejected across turns. A proposal is valid only for its current revision; confirmation recomputes the score and consumes the arm before invoking the existing engine. Manual fallback invalidates pending scores and never changes match state. Host must invalidate on manual actions, navigation, reconnect, undo and state replacement. Browser classic script lookup fixed for lexical SeerVisit. Source epochs in tests are synthetic. Do not stamp an epoch onto incoming frames at receipt: that would falsely accept late frames. Whether hardware provides trustworthy visit identity or another safe boundary remains to be verified. No production integration, no automatic scoring, no live network traffic, no changes to the existing engine or video.
