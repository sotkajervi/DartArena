## Release blockers – owner decisions and verification
- Legal operator/contact; age policy; support and appeal channel; account deletion and retention; notification/versioning/acceptance if needed; jurisdiction and any consumer terms for paid services.
- Do not add a mandatory checkbox or claim acceptance until the final text and versioning are approved.
- Privacy notice: identify controller/contact; inventory each purpose, data categories, legal basis, recipients, any transfers/safeguards, retention, rights, complaints, mandatory data and any automated decisions. Verify Supabase, Cloudflare, GitHub hosting, captcha and other actual processors and configurations, audio/video paths, technical media logs, report evidence, local storage and analytics. Do not assume video is never stored or that all data is deleted on account deletion. Verify the live settings and contracts before stating facts. 
- Code-based observations to verify: profile data, match and tournament records, confidential player reports and optional avatar evidence, suspension history, direct-challenge blocks, technical reports and media telemetry. Existing report-evidence cleanup code uses 30 days; media telemetry retention was configured separately and requires live verification. Distinguish raw evidence from report text and audit records.
